# Icônes de référence (à déposer ici)

Déposer ici les icônes supplémentaires dans le même style que la planche « Yeti » (voir `docs/ASSETS.md`,
section « Icônes supplémentaires souhaitées »). Un fichier par icône, PNG ≥ 256 px, fond uni ou transparent,
nom explicite (`bulb.png`, `music-note.png`, `trophy-gold.png`…).
Elles seront redessinées en vecteur (comme les autres) puis ajoutées à `scripts/generate_vector_icons.py`.
